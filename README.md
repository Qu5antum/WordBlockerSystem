# WordBlocker

Экспериментальное Android-приложение для обнаружения заданных слов и фраз в текстовых полях поддерживаемых приложений. При обнаружении совпадения приложение может очистить поле ввода и отправить пользователя на главный экран.

> [!WARNING]
> Используйте приложение только на собственном устройстве или с явного согласия его владельца. Для работы предусмотрены права администратора устройства и служба специальных возможностей. Служба специальных возможностей может получать текст и сведения о содержимом окон; при срабатывании приложение способно очистить ввод, вернуться назад или открыть главный экран. Это может помешать обычному использованию устройства.
>
> Перед включением прав проверьте исходный код и протестируйте приложение на устройстве, которое можете восстановить. Не используйте его как средство защиты или родительского контроля, которому можно доверять: фильтр может ошибаться, а список поддерживаемых приложений и экранов ограничен. Чтобы удалить приложение, сначала отключите службу специальных возможностей и деактивируйте приложение в настройках администратора устройства Android.

## Как работает приложение

- В `MyAccessibilityService` задан список слов для проверки и список пакетов приложений, в которых обрабатываются события ввода. В текущем исходном коде слова `bad_word1` и `bad_word2` — демонстрационные заполнители, а не готовый список.
- Текст нормализуется (в частности, удаляются пробелы и знаки препинания) и проверяется на точное и приблизительное совпадение. Это может приводить как к пропускам, так и к ложным срабатываниям.
- При обнаружении совпадения приложение очищает доступное для редактирования поле, а затем пытается вернуться назад и открыть главный экран.
- `MainActivity` запрашивает активацию администратора устройства при запуске. Защита настроек также зависит от службы специальных возможностей и не является гарантированной.
- Код не содержит серверной синхронизации или сетевого API. При этом служба обрабатывает содержимое окон на устройстве; перед использованием оцените последствия предоставления ей такого доступа.

## Сборка и запуск

1. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
2. Соберите и установите приложение на тестовое устройство с Android 7.0 (API 24) или новее.
3. При запуске Android может предложить включить администратора устройства. Службу специальных возможностей при необходимости нужно отдельно включить в системных настройках Android.
4. Для проверки используйте тестовые слова и приложения. Перед использованием замените демонстрационные заполнители в списке слов.

Параметры проекта: `minSdk = 24`, `compileSdk = 37`, `targetSdk = 37`, Java 11. Для сборки из PowerShell можно выполнить:

```powershell
.\gradlew.bat assembleDebug
```

## Важные файлы исходного кода

Файлы находятся в `app/src/main/java/com/example/wordblocker/`.

| Файл | Назначение и предупреждение |
| --- | --- |
| `MainActivity.kt` | Экран приложения, запрос администратора устройства и проверка пароля. Пароль для отключения защиты хранится прямо в исходном коде, поэтому его нельзя считать секретом или надёжной аутентификацией. Не публикуйте сборку как средство защиты. |
| `MyAccessibilityService.kt` | Основная логика фильтра и проверки экранов настроек. Службе требуется доступ к содержимому окон; она может очищать текст и выполнять системные действия «Назад» и «Главный экран». Изменяйте этот файл и проверяйте поведение особенно осторожно. |
| `MyAdminReceiver.kt` | Обработчик включения и отключения администратора устройства. Администратор может затруднить удаление приложения, пока его не деактивируют в системных настройках. |
| `NoPasteEditText.kt` | Поле ввода, блокирующее вставку и некоторые текстовые подтверждения клавиатуры длиннее трёх символов. Это ограничение может нарушать обычный ввод и поведение разных клавиатур. |

Также важны файлы вне каталога Kotlin:

- `app/src/main/AndroidManifest.xml` — объявляет экран, службу специальных возможностей и администратора устройства.
- `app/src/main/res/xml/accessibility_service_config.xml` — определяет типы событий и возможность читать содержимое окон.
- `app/src/main/res/xml/device_admin_config.xml` — объявляет политику администратора устройства.
- `app/src/main/res/layout/activity_main.xml` — разметка экрана ввода пароля.

## Отключение разрешений и удаление

В системных настройках Android отключите службу WordBlocker в разделе специальных возможностей, затем деактивируйте WordBlocker в разделе приложений-администраторов устройства. После этого удалите приложение обычным способом. Названия разделов зависят от версии Android и производителя устройства.
